# Stayora — Student Housing Platform

Stayora is a student housing web application designed to help students discover verified PGs, single rooms, shared flats, hostels, and roommates near their campus with zero brokerage.

---

## 🌟 Key Features

* **OTP Authentication**: Secure login via email or phone using Firebase & EmailJS (with demo fallback mode).
* **Smart Search & Filters**: Search by college/location and filter by occupancy, category (Boys/Girls/Coliving), and budget.
* **Campus Distance Calculation**: Calculates exact distance from campus using the Haversine formula (2km, 5km, 10km, 25km radius).
* **Interactive Map**: Location display and custom map pin picker powered by Leaflet.
* **OCR Student Verification**: In-browser college ID card scanning powered by Tesseract.js.
* **In-App Messaging & Visits**: Private chat with property owners and visit scheduling.
* **Roommate Finder**: Post and browse roommate requests easily.

---

## 🛠️ Tech Stack

* **Frontend**: HTML5, CSS3, JavaScript (ES6)
* **Libraries & APIs**: Leaflet.js, Firebase Auth, EmailJS, Tesseract.js, Socket.io
* **Storage**: LocalStorage for client-side state persistence

---

## 🚀 How to Run Locally

1. Clone or download this repository.
2. Open `stayora student housing.html` directly in any modern web browser.
